## Economy stress result

The payout rule remains:

```text
Credits = round_half_up(B × (0.50 + 0.35 × integrity + 0.15 × pace))
```

The design has a healthy soft-completion floor: a valid delivery earns between
`0.50B` and `1.00B`. A pristine long drift can finish after the pace bonus has
ended and still earn `0.85B`. Grade explains condition and pace but never
multiplies the award.

The final convergence simulation intentionally did not hide two open risks.
With illustrative learned medians `30/60/90 s`, `R=100`, and authored `H=12 s`,
the learned-clean full-cycle rate spread changes with actual interaction
overhead:

| Actual overhead | Max/min learned-clean rate spread |
| ---: | ---: |
| `4 s` | `13.939%` |
| `8 s` | `6.284%` |
| `12 s` | `0.493%` |
| `16 s` | `5.300%` |
| `20 s` | `10.294%` |

`H=12 s` is therefore a provisional authoring seed, not proof. The eventual
global allowance must come from measured complete cycles, then all literal
bases must be versioned together. Target max/min spread is `<=5%`; `5–15%`
requires re-authoring; `>15%` is a hard stop.

One maximum `24%` cargo episode at full pace earns about `91.6% B`. In the
illustrative medium and long jobs, that synthetic strategy can beat the
learned-clean Credit rate by roughly `0.26–0.30%`. This is small, but it is a
literal unresolved anti-exploit result. Native wall-pressure driving must fail
to dominate respectable play before contract values or prices can freeze.

The earlier `80/160` paint/trail shelf remains a conditional experiment only.
A `-10%` base perturbation makes the completion-floor “one short repeat after
both purchases” example miss by `22` Credits. No price promise belongs in Gate
B or in implementation authority before real cadence exists.

## Exact-grade repair requirement

The float-based iteration-03 study model misclassifies exact grade thresholds.
An exhaustive integer-grid comparison found `55` disagreements among
`3,004,001` points, including exact `Q=45`, `65`, and `82` cases.

Product grade evaluation must therefore:

- consume the same frozen integer integrity, elapsed, and reference evidence
  as the canonical receipt;
- use integer, Decimal, or exact-rational arithmetic;
- derive the grade inside the evaluator or bind it with an exact fingerprint;
- test both sides of every `45/65/82/94` boundary and each S/A/B condition or
  ratio gate; and
- never accept a display-supplied S/A/B/C/D label as authority.

This cannot mint Credits under the current rules, but a false displayed grade
would still break trust in the receipt.
