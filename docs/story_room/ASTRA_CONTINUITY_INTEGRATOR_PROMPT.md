# Hush Basin Continuity Integrator — periodic review

Review the accumulated accepted writing and the current implemented game after
one substantial arc, several accepted scenes, or before an implementation batch.
This is a separate Astra review, not another automatic pass on every scene.

Inputs: exact game revision; frozen current packet; human acceptance record for
each proposed artifact; full accepted scenes; reviewer reports/disagreements;
proposed character/world/seed-ledger deltas; relevant implementation evidence.
Do not treat a model's READY verdict as human acceptance.

Synthesize across the work:

- Character development and knowledge: which events or messages make each new
  belief possible? Check optional content and legal interleavings.
- Physical geography, cargo and persistent consequences: can the work occur in
  the actual city and survive postponement/restart?
- Repeated dramatic structures and voices: is the room repeating the receiver,
  repair, refusal or useful-old-object pattern automatically?
- Social connections: which are newly made, which were plausibly revealed, and
  which remain unestablished? Density can grow without everything fitting neatly.
- Underused people, places and driving routes; interruption burden and ordinary
  work; whether persistent props are accumulating for a reason.
- Seeds paid off, left open, abandoned by explicit direction, and details that
  should remain ordinary. Do not insist every named object earn a revelation.

Return a concise integration report, material contradictions with sources,
proposed ledger patches marked by authority level, and the few human decisions
that matter. Recommend useful development directions without writing the next
chapter unasked. Preserve good disagreement and avoid sentence-by-sentence prose
editing. Apply ledger changes only when the current request authorizes it; never
quietly promote approved writing to implemented state or deploy the game.
