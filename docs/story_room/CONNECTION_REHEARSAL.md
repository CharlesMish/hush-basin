# Bounded facts/transport rehearsal

This is a setup assignment, not fiction or a quality evaluation. No new story,
canon, mission, character or Chapter 4. It tests the native Opus delegation,
artifact return, independent review, same-agent revision and finite stop.

Producer uses `claude-opus-5-5`, 300k context, high effort, fast off through the
existing signed-in Cursor route and existing spending settings. Start from the
exact tooling commit supplied in the group, whose game is still `5be7fee…`.
Record returned model/settings/agent identity. If explicit selection or pinned
source fails, stop; no Auto/direct-API fallback.

Write only to a new absolute directory **outside** the Cursor agent's checkout.
No tracked edits, commits, push, PR, publication, installation, schedules or
other account changes. Final-reference the output and its SHA-256 for native
artifact transfer. Producer records/verifies the copied artifact in the shared
Grok run before Examiner reads it.

## Writer turn 1

Return at most 300 words: five factual entries with repository source paths.

1. Ren's current portrait location versus the anonymous Market mail lead.
2. Tess's practical stop coordinate/radius versus the physical counter.
3. Whether a story delivery requires a particular advised road or Hop.
4. The sleeve's actual fault, sound prior patch and new lining treatment.
5. What completes Chapter 3 and whether its two threads have a fixed order.

Use the frozen packet and actual relevant code. Say unknown rather than fill a
gap. Include a proposed-ledger-changes entry of “none” if these are already
established facts. Do not draft dialogue, tickets, a chapter or an emotional arc.

## Examiner pass 1 and writer turn 2

Examiner checks those five entries against the same source and returns the
normal verdict/findings/protected-material contract. It may return no findings;
do not manufacture an error for the test. Producer sends the complete report
back to the **same Opus agent**. Opus returns a separately saved revision (or an
explicit no-change artifact if warranted), with a short findings response.
Verify the second artifact transfer and source/ref provenance again.

Examiner performs one acceptance pass. **Stop after two writer turns and two
examiner passes maximum**, even if a blocker remains. This narrower rehearsal
cap overrides the general loop's optional third writer turn. No additional
diagnostic writer calls or automatic retry after an ambiguous launch outcome.

Final record: actual model/settings/agent ID, both writer artifacts/hashes,
reports, verified transfer paths, writer diff/activity result, turn counts,
remaining unknowns, and idle state. Exact charged pool/cost remains unverified
unless the account actually exposes it. A successful rehearsal establishes the
connection, not prose quality, owner acceptance or safety of unattended use.
