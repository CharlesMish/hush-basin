# District Zero P1A — Vehicle Integration R7 owner review

Double-click `PLAY_DISTRICT_ZERO_VEHICLE_R7.command` to play.

On the first launch from a clean extraction, the launcher briefly prepares and
validates Godot's local script-class cache with the required exact engine, then
opens the game. Later launches reuse that local cache.

R7 retains the complete Terrain Polish R6 game and replaces only the craft's
primitive presentation subtree with the validated native-Godot Babylon-transfer
visual rig. SPREAD, intermediate transformation choreography, DRIVE seating,
the late propulsion-can reveal, and the inherited clearance energy cue are
presentation-only.

Movement, tuning, transform timing, collider, probes, hazard cast, terrain,
world geometry, walls, routes, map, camera, lighting, shadows, and thresholds
remain unchanged. The visible model intentionally does not alter the fixed
gameplay collider. This is an owner-review build, not P1A PASS or Human World
Gate authorization.
